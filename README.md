\# Proyecto Juego



\## Descripción

Este proyecto fue desarrollado en Java utilizando el entorno de desarrollo Apache NetBeans. Su objetivo es implementar un programa mediante el lenguaje de programación Java.



\## Requisitos

\- Tener instalado Java JDK.

\- Contar con Apache NetBeans.

\- Tener acceso a los archivos del proyecto.



\## Instalación

1\. Descargar o clonar el repositorio desde GitHub.

2\. Abrir Apache NetBeans.

3\. Seleccionar la opción Abrir proyecto.

4\. Buscar la carpeta del proyecto Juego.



\## Ejecución

1\. Abrir el proyecto en NetBeans.

2\. Localizar el archivo principal `Principal.java`.

3\. Ejecutar el programa utilizando el botón Run Project o presionando F6.
